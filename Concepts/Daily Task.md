# Daily Task

## Definition
A small task for today that moves the user closer to the current [[Station]]. Generated by AI based on already completed tasks — this is the [[Plan Adaptation]] mechanism.

## Rules
- A [[Task]] with `type = "daily"`.
- Has `estimatedMinutes` and `progressContribution` (contribution to station progress, %).
- Generation costs 1 [[Coins|coin]].

## Implemented in
[[AI Module]] (`POST /ai/daily-tasks`), [[Task Module]] (`GET /tasks/goals/:goalId/daily-tasks`).
